🔮 COMPENDIO D&D 5e - MÓDULO DELTA: SISTEMA DE MAGIA Y CONJUROS

Referencia Estricta: SRD 5.2.1 | Uso: Motor de Lanzamiento, Grimorios y Slots

📐 1. Estructura y Niveles de Conjuros

La magia en D&D 5e está rígidamente tasada por niveles de poder (del nivel 0 al 9) y requiere una infraestructura de almacenamiento de estado en el backend:

  • Trucos (Nivel 0): Conjuros simples que se pueden lanzar a voluntad de forma ilimitada. No consumen recursos de la base de datos (slots).
  • Conjuros de Nivel (1-9): Requieren la existencia y el consumo de un Espacio de Conjuro (Spell Slot) del nivel correspondiente. Si el array de slots del personaje para ese nivel está a 0, el backend debe rechazar el lanzamiento.
  • Restauración de Espacios: Todos los espacios de conjuro gastados se restablecen al máximo tras completar un Descanso Largo.

⚡ 2. Mecánicas de Lanzamiento y Parámetros Estrictos

Cada vez que el backend valide la acción "Lanzar un conjuro", debe comprobar cuatro variables físicas del objeto conjuro antes de enviar la orden a la IA:

  • Tiempo de Lanzamiento: Generalmente 1 Acción, 1 Acción Adicional (Bonus Action) o 1 Reacción. *(Regla estricta: si lanzas un conjuro usando una Acción Adicional, el único otro conjuro que puedes lanzar en ese turno debe ser un Truco con un tiempo de lanzamiento de 1 acción)*.
  • Componentes: Verbales (V), Somáticos (S) o Materiales (M). Si un componente material especifica un coste en piezas de oro (po), el backend debe verificar si el jugador lo posee en su JSON de inventario.
  • Duración e Instantáneos: Los conjuros instantáneos resuelven su efecto y desaparecen. Los de duración persisten en el tiempo.
  • Concentración [Mecánica Crítica]: Ciertos conjuros de duración exigen concentración. Un personaje **solo puede concentrarse en un conjuro a la vez**. Si sufre daño mientras se concentra, el backend debe forzar una **Tirada de Salvación de Constitución (CD 10 o la mitad del daño recibido, el valor que sea mayor)**. Si falla, el conjuro activo se cancela automáticamente.

📊 3. Las Matemáticas de la Magia (CD y Ataque Mágico)

Las clases mágicas utilizan una característica clave (Inteligencia para Magos, Sabiduría para Clérigos, Carisma para Bardos). El backend computará de forma determinista dos valores estáticos para la ficha de personaje:

  • Modificador de Ataque de Conjuro: Mod. Característica Mágica + Bonificador de Competencia. Se usa cuando el conjuro exige una tirada de d20 para impactar a la CA del enemigo (Ej: Descarga de fuego).
  • CD de Salvación de Conjuros: 8 + Mod. Característica Mágica + Bonificador de Competencia. Se usa cuando el objetivo debe resistir el hechizo. El enemigo tirará el d20 y deberá igualar o superar esta CD para mitigar o anular el efecto (Ej: Bola de fuego).

📖 4. Integración Narrativa para el Dungeon Master (IA)

El LLM debe ceñirse a las limitaciones espaciales del conjuro inyectadas por el sistema:

  1. Áreas de Efecto Oficiales: Respetar la geometría descrita (Línea, Cono, Cubo, Esfera o Cilindro) para describir a qué elementos u objetivos del entorno afecta el hechizo.
  2. Componentes Narrativos: Describir cómo el personaje entona las palabras místicas (V) o gesticula con las manos libres (S) para dotar de inmersión técnica al juego, deteniendo la escena si las condiciones impiden el lanzamiento (ej: si el personaje está amordazado, no puede lanzar conjuros con componente Verbal).
